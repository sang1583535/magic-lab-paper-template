\paragraph{How to cite.} This template uses \texttt{natbib} (author--year).
Common commands, with the example entries in \texttt{reference.bib}:
\begin{itemize}
    \item \texttt{\textbackslash citep\{vaswani2017attention\}} $\rightarrow$
          parenthetical: \citep{vaswani2017attention}.
    \item \texttt{\textbackslash citet\{he2016deep\}} $\rightarrow$ textual:
          \citet{he2016deep}.
    \item Multiple references:
          \texttt{\textbackslash citep\{lecun2015deep,goodfellow2016deep\}}
          $\rightarrow$ \citep{lecun2015deep,goodfellow2016deep}.
    \item With a note: \texttt{\textbackslash citep[see][Ch.~1]\{goodfellow2016deep\}}
          $\rightarrow$ \citep[see][Ch.~1]{goodfellow2016deep}.
    \item Preprint and website entries:
          \citep{touvron2023llama,magiclab2026}.
\end{itemize}
Cross-reference sections, figures, and tables with \texttt{\textbackslash cref},
e.g.~\cref{sec:method}, \cref{fig:teaser}, and \cref{tab:main-results}.
