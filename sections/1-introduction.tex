\section{Introduction}
\label{sec:intro}

This is the MAGIC Lab paper template. Replace the text in each section file under \texttt{sections/} with your own content; the text here briefly explains how to use the template and gives common writing conventions.

\paragraph{Files.} \texttt{main.tex} holds the title page (title, authors, affiliations, links) and includes one file per section from \texttt{sections/}. Put figures in \texttt{figures/}, larger tables in \texttt{tables/}, and BibTeX entries in \texttt{reference.bib}. The style is defined in \texttt{magicstyle/magic.cls}; you should not need to edit it.

\paragraph{Compiling.} Use \texttt{pdflatex} (default on Overleaf), \texttt{xelatex}, or \texttt{lualatex}, followed by \texttt{bibtex}. Use the class option \texttt{nologo} to remove the lab logo.

\paragraph{Writing the introduction.} A good introduction (about one page) follows this structure:
\begin{itemize}
    \item The problem and why it matters.
    \item What existing approaches do and the key gap they leave.
    \item Your key insight and the method that follows from it.
    \item How you evaluate it and the headline results.
    \item A short list of contributions.
\end{itemize}

\paragraph{Contributions.} In summary, our contributions are:
\begin{itemize}
    \item \textbf{A method.} We propose \method, which \dots
    \item \textbf{An evaluation.} We evaluate \method on \dots\ in simulation and on real robots.
    \item \textbf{An open release.} We release code, models, and data.
\end{itemize}

\paragraph{Comments.} Use the macros in \texttt{main.tex} for inline notes, e.g.\ \authorA{check this number}, and remove them before submission.
